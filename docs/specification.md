## 1. Идея и проблема

### 1.1. Идея

**Закрыть вкладку не значит потерять её.** Tabsurd — расширение Chrome, которое хранит окна и группы вкладок, восстанавливает пропавшие и освобождает память. На компьютере с video-analyzer оно ещё запоминает открытые видео и скачивает их в архив.

### 1.2. Проблема

Интересных видео в сети больше, чем успеваешь посмотреть, и они разбросаны по десяткам сайтов. Их открывают во вкладках «на потом», вкладок становится сотни, а каждая держит память: Chrome и весь компьютер начинают тормозить. Закрыть вкладку при этом страшно — видео может потеряться: его не найти снова, его удалят с сайта, а окна иногда пропадают сами, после сбоя или случайного закрытия. Ещё одна беда — повторы: открываешь то, что уже видел или уже скачал.

### 1.3. Как это решается

- хранит общий список сохранённых окон и групп вкладок, и их можно смело закрыть, освободив память;
- помнит все окна и вкладки и восстанавливает пропавшие;
- по желанию синхронизирует список между компьютерами и профилями одного аккаунта.

### 1.4. С video-analyzer

На компьютере с video-analyzer Tabsurd ещё и помогает разобраться с видео:

- запоминает каждое открытое видео и сколько его смотрели;
- показывает на странице, что видео уже открывалось или уже скачано;
- сам понимает по просмотрам, какие видео нравятся больше;
- по кнопке скачивает видео в папку модели в архиве, чтобы оно не пропало с сайта.

### 1.5. Для кого и границы

- Личный инструмент одного пользователя: сервер синхронизации на своём VPS, вход только с разрешённых аккаунтов (`docs/sync_server/specification.md`, раздел 1).
- Только компьютер, доступа с телефона нет.
- Не публикуется в Chrome Web Store, ставится распакованным (`docs/extension/technologies.md`, раздел 2.8).
- Видео скачивается только по кнопке, автоскачивания нет (раздел 3).
- Время просмотра и оценки не покидают компьютер с video-analyzer.

## 2. Части и режимы

### 2.1. Части

| Часть | Где | Роль |
|---|---|---|
| **Расширение Tabsurd** | в каждом профиле Chrome | весь интерфейс: плашки и кнопки на сайтах и собственные страницы расширения (`chrome-extension://…`). Хранит свой список вкладок и снимки окон |
| **Сервер синхронизации** | удалённо, свой VPS; репозиторий `tabsurd` | аккаунты профилей Chrome, сохранённые окна и группы и снимки окон для синхронизации между компьютерами (`docs/sync_server/specification.md`) |
| **Локальный сервис** | на компьютере с video-analyzer | часть video-analyzer: база просмотров, оценки, скачивание, VLC и Проводник (`video-analyzer/docs/local_service/local_service.md`) |
| **Prime Time** | на компьютере с video-analyzer | записывает просмотры из VLC в локальный сервис (`video-analyzer/docs/Prime Time/vlc_tracking.md`) |

Слово «backend» в документах не используется: всегда пишется, какой из двух серверов имеется в виду.

Связи только такие:

- Prime Time → локальный сервис;
- расширение → локальный сервис;
- расширение → сервер синхронизации.

Два сервера друг с другом не общаются.

### 2.2. Режимы

Режимы включаются независимо друг от друга:

| Режим | Что работает |
|---|---|
| **Только расширение** (любой компьютер, любой профиль) | сохранение и закрытие окон и групп, общий список, поиск, снимки и восстановление окон, список окон. Без времени просмотра, статистики и скачивания |
| **+ сервер синхронизации** | тот же список вкладок и снимки окон на всех компьютерах |
| **+ локальный сервис** (только один профиль на компьютере с video-analyzer) | время просмотра, оценки, статистика, просмотры из Prime Time, скачивание, плашки «уже открывалось» и «уже скачано» |

**Работа без сети.** Основная копия данных — в самом расширении (`docs/extension/technologies.md`). Без интернета работает всё, кроме синхронизации; изменения копятся и уходят на сервер, когда он снова доступен. Локальный сервис интернет не требует, кроме самого скачивания.

## 3. Принятые решения

- **Интернет локальному сервису — только для скачивания.** Ключ видео и канал определяются без обращения к сайту: по адресу и по открытой странице (`video-analyzer/docs/watch_stats.md`, раздел 2).
- **Учитываются все открытые видео** (в подключённом профиле).
- **Никакого автоскачивания.** Видео скачивается только по кнопке.
- **Качество скачивания — 1080p.**
- **Обложки не скачиваются и не хранятся.** У нескачанного видео обложка показывается прямо с сайта по адресу, у скачанного — кадр из файла.
- **Нет кнопки «Отпустить»**: закрытое и так не теряется (недавно закрытые, снимки окон), а «не понравилось» выражается симпатией ниже 5.
- **Нет лимита списка, вопроса при сохранении, еженедельного разбора и срока годности.** Видео, открытые на несколько секунд, сами уходят вниз при сортировке по баллу.
- **Только компьютер**, доступа с телефона нет.
- **Время просмотра и оценки не синхронизируются.** Они живут только в локальном сервисе.
- **Сквозного шифрования пока нет**, но формат синхронизации оставляет для него возможность (`docs/extension/specification.md`, раздел 6).
