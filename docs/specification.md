## 1. Зачем

Видео с разных сайтов открываются во вкладках быстрее, чем смотрятся. Закрыть вкладку страшно — вдруг видео потом не найти, а сотни открытых вкладок вешают Chrome и весь компьютер. Ещё видео повторяются: открывается то, что уже открывалось раньше. А лучшие видео хочется хранить у себя, потому что с сайтов их удаляют.

Tabsurd делает так, чтобы **закрыть вкладку не значило потерять видео**:

- запоминает каждое открытое видео и сколько его смотрели;
- показывает на странице, что видео уже открывалось или уже скачано;
- сам понимает по просмотрам, какие видео нравятся больше;
- по кнопке скачивает видео в папку модели в архиве.

Просмотры скачанных видео в VLC считает Prime Time. Обе программы пишут в одну базу по одной логике (`video-analyzer/docs/watch_stats.md`), поэтому история видео не обрывается в момент скачивания.

## 2. Части

Части разделены по ролям, а не по программам:

| Часть | Роль |
|---|---|
| **Prime Time** | записывает просмотры из VLC (`video-analyzer/docs/Prime Time/vlc_tracking.md`) |
| **Расширение Tabsurd** | записывает просмотры из браузера и содержит **весь интерфейс**: плашки и кнопки на сайтах и собственные страницы расширения (`chrome-extension://…`) со вкладками, списками и графиками (`docs/extension/specification.md`, раздел 3) |
| **Backend** | общий сервис video-analyzer на `localhost`, а не часть Tabsurd: хранит базу просмотров, считает оценки, скачивает, открывает VLC и Проводник и отдаёт данные. Статику не раздаёт (UI-3) |

Статистика — это данные, которые backend отдаёт расширению, а расширение рисует. Отдельной программы для графиков нет.

**Сборка расширения.** Все зависимости (npm), в том числе библиотека графиков, собираются вместе с кодом в бандл расширения с несколькими точками входа: скрипты на сайтах, страницы интерфейса, фоновый скрипт. Из интернета расширение ничего не загружает, поэтому работает и без него.

**Где лежит код** (`video-analyzer/docs/specification.md`, раздел 1.2): backend, Prime Time и общая логика просмотров — пакеты Python в `src/` (`backend`, `prime_time`, `watch_stats`), расширение — `extension/`, договор API — `api/openapi.yaml`.

Пользователь один (NFR-5), всё работает локально.

## 3. Принятые решения

- **Интернет — только для скачивания.** Backend обращается к сайтам только тогда, когда пользователь нажал «Скачать». Ключ видео и канал определяются без обращения к сайту: по адресу и по открытой странице (`video-analyzer/docs/watch_stats.md`, раздел 2).
- **Учитываются все открытые видео**, а не только сохранённые.
- **Никакого автоскачивания.** Видео скачивается только по кнопке.
- **Качество скачивания — 1080p.**
- **Обложки не скачиваются и не хранятся.** У нескачанного видео обложка показывается прямо с сайта по адресу, у скачанного — кадр из файла.
- **Нет лимита списка, вопроса при сохранении, еженедельного разбора и срока годности.** Видео, открытые на несколько секунд, сами уходят вниз при сортировке по баллу.
- **Только компьютер**, доступа с телефона нет.
