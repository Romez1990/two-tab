Связанные документы: `docs/specification.md` (идея и общие решения), `docs/extension/specification.md`, `docs/extension/technologies.md`, `docs/sync_server/specification.md`, `docs/sync_server/technologies.md`, `tidy-reel/docs/local_service/local_service.md`, `tidy-reel/docs/watch_stats.md`.

## Поиск и дубликаты (вне этапов)

Вкладки — без локального сервиса, поэтому можно делать в любой момент; архив — после поиска по базе в Tidy Reel (`tidy-reel/docs/plan.md`, «Поиск по архиву»).

- [x] «Умный поиск»: разбор запроса в дерево условий (И, ИЛИ, НЕ, фраза, скобки, `path:`, `url:`), часть слова, без регистра, `ё` = `е`, раскладка; тесты (`docs/extension/pages/search.md`, раздел 2).
- [x] Страница «Поиск»: открытые и сохранённые вкладки, недавно закрытые и снимки (выкл.), один список, «по совпадению» и «по дате», «Перейти к вкладке», «Перейти к группе» (колёсиком — в фоне).
- [x] Поиск по архиву на странице «Поиск»: галочка «Архив», ярлыки свёрнуты, «Открыть» и «Показать в папке».
- [x] История запросов: сохранение по Enter, недавние при клике, похожие при наборе, крестик «забыть» (`docs/extension/pages/search.md`, раздел 2.1). Синхронизация — на этапе 6.
- [x] Префиксы `name:`, `title:`, `channel:`, `song:`, `group:`, `any:`, `source:`, префикс перед скобками, ошибки разбора, строгая логика, подсказка о выключенном источнике; раскладка больше не учитывается (`docs/extension/pages/search.md`, раздел 2). Архив — после `tidy-reel/docs/plan.md`, «Префиксы поиска».
- [x] Поиск в адресе страницы: запрос, фильтры, сортировка, страница, «Назад» (`docs/extension/pages/search.md`, раздел 4).
- [x] Страница «Дубликаты»: адреса по `page_key`, от самых повторяющихся, список копий с «Перейти», «Закрыть», «Удалить из сохранённых» (`docs/extension/pages/duplicates.md`).
