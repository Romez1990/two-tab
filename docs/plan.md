# План работ: Tabsurd

Статус: план, 2026-10-11. Сделанное отмечается галочками. Коммит — в конце этапа.

Связанные документы: `docs/specification.md` (идея и общие решения), `docs/extension/specification.md`, `docs/extension/technologies.md`, `docs/sync_server/specification.md`, `docs/sync_server/technologies.md`, `video-analyzer/docs/local_service/local_service.md`, `video-analyzer/docs/watch_stats.md`.

Расширение и сервер синхронизации — в репозитории `tabsurd`; локальный сервис, `watch_stats` и Prime Time — в video-analyzer. Ссылки `video-analyzer/docs/…` ведут в репозиторий video-analyzer.

## Этап 1. Каркас расширения

- [x] Репозиторий `tabsurd`, структура из `docs/specification.md`, раздел 4; документы `docs/` переезжают туда.
- [x] `extension/`: WXT, React, Dexie, слои Feature-Sliced Design с проверкой импортов линтером, точки входа — фоновый скрипт, страницы, всплывающее окно, первый запуск. Скрипт на сайтах перенесён на этап 5: пустой скрипт только занимал бы память на каждой странице.
- [x] Постоянный ID (ключ в манифесте). Установка распакованным в профили — по README.
- [x] Эксперимент: сортирует ли Windows окна Chrome на панели задач по времени создания (`docs/extension/pages/windows.md`, раздел 1).

## Этап 2. Снимки окон и восстановление

- [x] Постоянный номер окна: по номеру Chrome, после перезапуска — по совпадению адресов со снимком (`docs/extension/specification.md`, раздел 3.1).
- [x] Текущий снимок и история снимков с хранением по возрасту (`docs/extension/pages/recovery.md`, раздел 1).
- [x] Проверка при запуске Chrome и уведомление о пропавших окнах.
- [x] Страница «Восстановление»: снимки, восстановление всего, окна или вкладок; вкладки выгружены.
- [x] Недавно закрытые вкладки, 30 дней.
- [x] Оформление на MUI (Material Design): всплывающее окно, «Восстановление», «Первый запуск», светлая и тёмная тема (`docs/extension/technologies.md`, раздел 2.2).

## Этап 4. Локальный сервис и скачивание

- [x] video-analyzer: `local_service` на FastAPI + dishka, слои, проверка Origin и ключа, порт 47810, lock-файл.
- [x] Подключение одного профиля и отказ остальным, «Отключиться от video-analyzer», команда в меню video-analyzer.
- [x] `api/openapi.yaml` из кода и копия в `tabsurd`, типы для расширения.
- [x] Расширение: первый запуск с подключением к локальному сервису.
Серверная часть — в `video-analyzer/docs/plan.md` («Сжатие видео», «Скачивание»). Здесь — расширение (`docs/extension/pages/downloads.md`).

- [x] Общий компонент пагинации (из «Сохранённых») и подсказка «умного» поля со знаком вопроса (`docs/extension/specification.md`, раздел 2).
- [ ] Куки сайта: разрешение `cookies`, передача сервису с каждым заданием и по его запросу после падения.
- [ ] Кнопка «Скачать» на странице видео (`docs/extension/pages/site_page.md`, раздел 3): «Уже скачано» до скачивания.
- [ ] Окно «Скачать»: найденная модель или выбор из нескольких, тег, «создать модель» с выбором категории, «папка без модели» (окно Windows, последние папки), пресет сжатия с правками на этот раз.
- [ ] Страница «Очередь скачивания»: группы (раскрыть, передвинуть, пауза, отменить), видео внутри группы (передвинуть, «Повторить», «Отменить»), прогресс скачивания и сжатия; у скачанного — «Показать в папке» и «Открыть».
- [ ] Пресеты сжатия в настройках: «По умолчанию» и пресеты сайтов, ползунки с процентами, «Умный момент времени» для обрезки, нормализация звука (`docs/extension/pages/settings.md`, раздел 4).
- [ ] Скачивание канала с фильтрами: период, диапазон «с № по №» с начала или с конца, длительность; «только с музыкой» — после распознавания музыки в video-analyzer.
- [ ] Подписки: кнопка «Подписаться», страница подписок, «Проверить сейчас», уведомления о новых и скачанных видео с «Показать в папке».

## Поиск и дубликаты (вне этапов)

Вкладки — без локального сервиса, поэтому можно делать в любой момент; архив — после поиска по базе в video-analyzer (`video-analyzer/docs/plan.md`, «Поиск по архиву»).

- [x] «Умный поиск»: разбор запроса в дерево условий (И, ИЛИ, НЕ, фраза, скобки, `path:`, `url:`), часть слова, без регистра, `ё` = `е`, раскладка; тесты (`docs/extension/pages/search.md`, раздел 2).
- [x] Страница «Поиск»: открытые и сохранённые вкладки, недавно закрытые и снимки (выкл.), один список, «по совпадению» и «по дате», «Перейти к вкладке», «Перейти к группе» (колёсиком — в фоне).
- [x] Поиск по архиву на странице «Поиск»: галочка «Архив», ярлыки свёрнуты, «Открыть» и «Показать в папке».
- [x] История запросов: сохранение по Enter, недавние при клике, похожие при наборе, крестик «забыть» (`docs/extension/pages/search.md`, раздел 2.1). Синхронизация — на этапе 6.
- [x] Страница «Дубликаты»: адреса по `page_key`, от самых повторяющихся, список копий с «Перейти», «Закрыть», «Удалить из сохранённых» (`docs/extension/pages/duplicates.md`).
