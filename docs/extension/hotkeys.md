# Горячие клавиши

Часть требований расширения Tabsurd, общее — `docs/extension/specification.md`. Решено 2026-10-13.

---

## 1. Глобальные клавиши

Команды браузера (`commands` в манифесте) работают на любой вкладке. Chrome разрешает задать по умолчанию не больше 4 сочетаний; пользователь переназначает их в `chrome://extensions/shortcuts`.

| Действие | Клавиша |
|---|---|
| Сохранить и закрыть текущее окно (`docs/extension/pages/saved.md`, раздел 1) — освободить ресурсы | `Alt+Shift+S` |
| Открыть форму «Скачать» для текущей страницы (`docs/extension/pages/downloads.md`, раздел 0) | `Alt+Shift+D` |

- Всплывающее окно по клавише не открывается, поиск — тоже: поиск открывается кнопкой во всплывающем окне.
- Обработка — `browser.commands.onCommand` в фоне; вызывает те же функции, что кнопки.
- В настройках — ссылка «Изменить горячие клавиши»: открывает `chrome://extensions/shortcuts` (такую страницу можно открыть только через `tabs.create`).

## 2. Клавиши на страницах расширения

Срабатывают, только когда фокус не в поле ввода (кроме `Esc`).

| Где | Клавиши |
|---|---|
| Везде | `/` — фокус в поиск или фильтр; `Esc` — снять фокус, закрыть диалог; `?` — шпаргалка клавиш страницы |
| Списки (Поиск, Сохранённые, Корзина) | `↑`/`↓` и `J`/`K` — выбор строки; `Enter` — открыть; `Delete` — удалить (в корзину, `docs/extension/pages/trash.md`); `←`/`→` — страницы |
| Дубликаты вкладок | `↑`/`↓` и `J`/`K` — выбор копии; `Enter` — перейти; `Delete` — закрыть или удалить из сохранённых |
| Очередь скачивания | `↑`/`↓` и `J`/`K` — выбор; `P` — пауза или продолжить; `R` — повторить ошибку; `Delete` — убрать (в корзину) |
| Форма «Скачать» | `Enter` — «Скачать» с тем, что сейчас в форме; `Esc` — закрыть |

- Хук `useHotkeys` в `shared/lib`, без библиотек. Шпаргалка `?` — компонент в `shared/ui`.

## 3. Подписи в интерфейсе

Клавиши подписаны в самом интерфейсе, чтобы о них не забыть:

- у кнопки с клавишей — подсказка с ней: «Удалить — Del»;
- внизу списка — строка-напоминание: `↑↓ J K выбор · Enter открыть · Del удалить · ? все клавиши`;
- у глобальных команд подсказки во всплывающем окне берут клавишу из `browser.commands.getAll()`: переназначенная клавиша показывается правильно, неназначенная не показывается.
