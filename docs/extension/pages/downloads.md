# Скачивание: форма «Скачать», очередь, подписки

Часть требований расширения Tabsurd, общее — `docs/extension/specification.md`.
Связанные документы: `video-analyzer/docs/downloader.md`, `video-analyzer/docs/compression.md`.

---

> **Назначение.** Скачивание видео предназначено исключительно для личного некоммерческого использования: для просмотра в отсутствие доступа к интернету или электроснабжения. Скачанные материалы не распространяются, не передаются третьим лицам, не демонстрируются публично и не используются в коммерческих целях. Соблюдение правил сайтов-источников и прав правообладателей остаётся на ответственности пользователя.

Только в профиле, подключённом к video-analyzer. Скачивает локальный сервис (модуль `downloader`); очередь, сайты, докачка после падения и куки описаны в `video-analyzer/docs/downloader.md`. Со стороны пользователя:

- **Только по кнопке** на странице видео (`docs/extension/pages/site_page.md`, раздел 3) или на страницах расширения.
- **Куда.** В папку модели, которую локальный сервис находит по ссылкам `.url` на канал, по нику из адреса и по отображаемому имени канала (`video-analyzer/docs/downloader.md`, раздел 4).
  - Нашлась одна модель — в её `New` или туда, куда скачивали эту модель в прошлый раз (раздел 0). В момент скачивания можно выбрать другую папку внутри модели (тег).
  - Нашлось несколько или только по отображаемому имени — пользователь выбирает из списка.
  - **Модели нет** — пользователь выбирает: создать модель (категорию выбирает сам, как «Create model from URL», `video-analyzer/docs/web_links.md`, раздел 6) или скачать в папку без модели (окно выбора папки Windows, последние папки — списком).
- **Уже скачано** — видно на кнопке «Скачать» до скачивания: сервис узнаёт видео по сайту и id.
- **Место на диске** заранее не проверяется. Если место кончилось, недокачанный файл удаляется, и пользователь видит сообщение об этом.
- **Куки.** Расширение всегда передаёт локальному сервису куки сайта этого видео (разрешение `cookies` и доступ к сайту): заранее не известно, закрыто ли видео. Куки живут только в памяти сервиса и во временном файле на время скачивания.
- **Сжатие.** После скачивания видео сжимается в AV1 по пресету сайта (`video-analyzer/docs/compression.md`). В форме «Скачать» показан пресет, и для этого видео его можно поменять. Сами пресеты редактируются в настройках расширения, хранятся в локальном сервисе.
- **Очередь** видна на страницах расширения: прогресс скачивания и сжатия, ошибки, кнопки «Повторить» и «Отменить»; у скачанного — «Показать в папке» и «Открыть».
- **Канал целиком, группы в очереди, только видео с музыкой** — `video-analyzer/docs/downloader.md`, разделы 2.1, 6–8.
- **После скачивания** просмотры видео в VLC прибавляются к тому же видео, что и просмотры в браузере.

## 0. Форма «Скачать» во всплывающем окне

Решено 2026-10-13. Отдельного окна и вкладок скачивание не открывает: форма — внутри всплывающего окна. Плашка на сайте остаётся маленькой.

- **Как открывается:**
  - `Alt+Shift+D` (`docs/extension/hotkeys.md`) и кнопка «Скачать» на плашке сайта — всплывающее окно открывается сразу с формой (`action.openPopup()` из фона, Chrome 127+). Если открыть не удалось (окно браузера не в фокусе), плашка подсказывает «нажмите Alt+Shift+D»;
  - обычное открытие всплывающего окна — кнопка «Скачать», по ней форма открывается внутри окна.
- **Одна форма для видео и канала.** Поля:
  - **папка** — раздел ниже;
  - **пресет сжатия** — по сайту, можно сменить;
  - **«Только с музыкой»** — недоступна до распознавания музыки (`video-analyzer/docs/music_detection.md`);
  - у канала — **какие видео:** все, с номера по номер, с даты по дату; у подписки ещё «только новые, с этого момента». Видео всегда качаются от старых к новым, выбора порядка нет.
- **Кнопки:** «Скачать» (по умолчанию) — разовое скачивание; у канала ещё «Подписаться». Вариант «только новые» есть только у подписки: при нём «Скачать» недоступна.
- **Enter** применяет то, что сейчас в форме, — как «Скачать». **Esc** закрывает окно без скачивания.
- **После нажатия** видео ставится в очередь, окно закрывается, плашка на сайте показывает «✓ В очереди: Модель\Тег». Вкладка с видео не закрывается: можно смотреть и скачивать дальше. Очередь — по кнопке во всплывающем окне.
- **Папка подставляется так:**
  - модель известна, и в неё уже скачивали — тот же путь, что в прошлый раз (например `Модель\Тег`);
  - модель известна, но в неё ещё не скачивали — папка модели;
  - модели нет — последняя папка без модели, куда скачивали.
- **Выбор папки** — внутри формы, без окна Windows: всплывающее окно закрывается, как только теряет фокус. Обзор показывает текущую папку, её подпапки и теги: можно зайти глубже и подняться выше (список папок даёт локальный сервис). Ниже:
  - **недавние папки без модели** — 7 последних, куда скачивали; последняя использованная встаёт первой;
  - «Создать модель»;
  - «Папка без модели».
- Отдельное окно «Скачать» убирается.
