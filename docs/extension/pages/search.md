# Страница «Поиск»

Часть требований расширения Tabsurd, общее — `docs/extension/specification.md`.
Связанные документы: `tidy-reel/docs/local_service/local_service.md`, раздел 7.2 (поиск по архиву), `tidy-reel/docs/indexing.md`.

---

## 1. Где искать

Галочками; по умолчанию включены первые три:

| Источник | Что ищется | По умолчанию |
|---|---|---|
| **Открытые вкладки** | заголовок, адрес (`chrome.tabs`) | вкл. |
| **Сохранённые вкладки** | заголовок, адрес, название группы | вкл. |
| **Архив** | видео в базе индексации Tidy Reel: имя файла, путь от корня архива, адреса источников, название и канал на сайте, найденные песни | вкл. |
| **Недавно закрытые** | заголовок, адрес | выкл. |
| **Снимки окон** | заголовок, адрес | выкл. |

- Открытые вкладки других компьютеров не ищутся: синхронизация и так делает их одинаковыми (`docs/extension/specification.md`, раздел 3.3).
- **Архив** — только в профиле, подключённом к Tidy Reel; иначе галочка недоступна. Ищет локальный сервис по базе индексации, **диск не читается**. База обновляется ежедневной индексацией (`tidy-reel/docs/indexing.md`) и сразу после скачивания.
- **Ярлыки.** Видео находится и по своему имени и пути, и по именам и путям ярлыков на него. В результатах — только само видео, один раз, даже если совпал только ярлык. У видео — «есть 2 ярлыка»; список их папок свёрнут и раскрывается по клику.

## 2. Умный поиск

Поиск запускается **по Enter**, а не при вводе. Решено 2026-10-14:

- **Текст запроса не менялся** с последнего поиска — смена любого фильтра, галочки «где искать» или сортировки сразу запускает поиск заново, без Enter.
- **Текст изменён, а Enter не нажат** — фильтры и сортировка поиск не запускают, только Enter. Если текст вернули к последнему запущенному, фильтры снова запускают сразу.

Подсказка у поля (знак вопроса, `docs/extension/specification.md`, раздел 2):

| Запрос | Что найдёт |
|---|---|
| `rain dance` | оба слова, в любом порядке (И) |
| `rain \| snow` | любое из слов (ИЛИ) |
| `rain -remix` | `rain`, но без `remix` (НЕ) |
| `"rain dance"` | точную фразу |
| `(rain \| snow) dance` | группировка скобками |
| `path:Indigo` | слово в пути к папке от корня архива |
| `path:"R lang T" rain` | `rain` в имени файла, в пути есть `R lang T` |
| `url:tiktok` | слово в адресе |
| `any:cat` | слово где угодно: в названии, пути, адресе, названии на сайте, канале, песне, группе |
| `any:(cat \| kitty)` | префикс перед скобками действует на всю группу |
| `-channel:x source:archive` | видео архива, у которых канал не содержит `x` |
| `"12:30"` | двоеточие в обычном тексте — только в кавычках |

**Префиксы.** Слово без префикса ищется в названии, как `name:`.

| Префикс | Где ищет | У каких источников есть |
|---|---|---|
| `name:` | название: имя файла и имена ярлыков на него, заголовок вкладки | у всех |
| `path:` | путь к папке от корня архива (как в базе: с имени категории), и пути ярлыков | архив |
| `url:` | адрес вкладки; адреса источников видео (`tidy-reel/docs/downloader.md`, раздел 5) | у всех |
| `title:` | название видео на сайте, сохранённое при скачивании | архив |
| `channel:` | канал или автор на сайте, сохранённый при скачивании | архив |
| `song:` | название найденной в видео песни | архив |
| `group:` | название группы | сохранённые вкладки |
| `any:` | всё перечисленное выше сразу | у всех |
| `source:` | источник: `open`, `saved`, `archive`, `closed`, `snapshot` (раздел 1) | у всех |

- **Строгая логика.** Если у источника нет поля префикса, условие для него ложно, а с минусом — истинно. `channel:x` вкладок не найдёт, `channel:x | url:y` найдёт и вкладки по адресу, а `-channel:x` пропустит все вкладки. Нужна строгость — добавляется `source:`: `-channel:x source:archive`.
- **Галочки «где искать» — внешняя граница.** Выключенный источник не ищется, что бы ни было в запросе. Если запрос упоминает в `source:` выключенный источник, под полем подсказка: «Недавно закрытые выключены в фильтрах»; галочка сама не включается.
- **`source:`** сравнивается целиком, не как часть слова.
- **Ошибки разбора** показываются под полем, поиск не запускается: неизвестный префикс (`chanel:x`) — со списком префиксов; неверное значение `source:` (`source:arch`) — со списком значений.
- Регистр не важен; слово ищется как часть (`danc` найдёт `Dancing`); `ё` и `е` не различаются. Раскладка клавиатуры не исправляется: запрос пишется в той раскладке, в какой нужно.
- **Один разбор на всё.** Расширение разбирает запрос в дерево условий. Вкладки проверяет само, а для архива отправляет дерево локальному сервису, который строит из него SQL. Синтаксис везде один, разбор не дублируется.

### 2.1. История запросов

Чтобы удачный запрос можно было повторить.

- **Сохраняется по Enter:** запрос, который запустили, попадает в историю. Повторный — не дублируется, а поднимается наверх как самый недавний.
- **Клик по пустому полю** — список недавних запросов, самые новые сверху.
- **При наборе** — запросы из истории, похожие на набранное, по степени похожести.
- **Выбор запроса** из списка подставляет его в поле и сразу запускает поиск.
- **Крестик** у каждого запроса — забыть его.
- **Похожие:** сначала запросы, которые начинаются с набранного, потом те, где набранное внутри, потом отличающиеся на одну-две опечатки; при равенстве выше частые и недавние. Регистр и `ё`/`е` не важны, как в самом поиске.
- **Хранится вся история**, без ограничения числа; если разрастётся — решим потом.
- **Одинаковая на всех компьютерах** — через сервер синхронизации (`docs/sync_server/specification.md`, раздел 3), а не `chrome.storage.sync`. Без сервера — только на этом компьютере.

## 3. Результаты

- **Один общий список** с меткой источника у строки, с общей пагинацией (`docs/extension/specification.md`, раздел 2).
- **Сортировка** — переключатель:
  - **«По совпадению»** (по умолчанию): точное совпадение фразы, затем совпадение в названии, а не в пути, затем слово в начале названия; при равенстве — новее выше;
  - **«По дате»**: у файла — дата изменения, у сохранённой вкладки — дата сохранения, у открытой — последний переход на неё;
  - **«По баллу»** — самые любимые видео сверху: итог с симпатией за всё время (`video-analyzer/docs/watch_stats.md`, раздел 5.2). Строки без балла (вкладки, ни разу не смотренные видео) — в конце, между собой по совпадению.
- **Балл у видео архива** — итог за всё время, рядом с именем. У ни разу не смотренных балла нет.
- **Карта просмотра** — у видео архива от 2 минут: какие места смотрелись чаще; клик по месту открывает видео в VLC с этой секунды (`video-analyzer/docs/watch_stats.md`, раздел 3.5).
- **Действия:**
  - открытая вкладка — **«Перейти к вкладке»**: активирует вкладку и выводит её окно на передний план;
  - сохранённая вкладка — **«Перейти к группе»**: в новой вкладке открывается «Сохранённые» с раскрытой группой и выделенной вкладкой; страница поиска остаётся открытой. Клик колёсиком — новая вкладка открывается в фоне;
  - видео архива — **«Открыть»** (`os.startfile`) и **«Показать в папке»**. Перед действием сервис проверяет, что файл на месте; если нет — «Файл переместили, нужна индексация».
  - скачанное видео архива — ещё **«Открыть страницу видео»**: адрес берётся из базы загрузчика по сайту и id (`tidy-reel/docs/downloader.md`, раздел 5) и открывается в новой вкладке. У видео, скачанных не через загрузчик, кнопки нет.

## 4. Поиск в адресе страницы

Чтобы поиск переживал перезагрузку, а в разных вкладках были разные поиски и не мешали друг другу.

- **В адресе** — запущенный запрос, галочки «где искать», фильтры, сортировка и номер страницы: `app.html#search?q=rain&in=open,archive&sort=date&page=3` (`in` — галочки). Только то, что отличается от значения по умолчанию.
- **Страница без параметров** открывается пустой: последний поиск нигде, кроме адреса, не хранится.
- **История браузера.** Каждый запущенный поиск (Enter, смена фильтра или сортировки) и переход на другую страницу результатов — новая запись: «Назад» возвращает прошлый поиск или прошлую страницу. Набор текста без Enter адрес не меняет.
- **Номер страницы** сбрасывается на первую при новом запросе, смене фильтра или сортировки. Если после перезагрузки страниц стало меньше — показывается последняя.
