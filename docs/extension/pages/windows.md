## 1. Порядок окон

Список окон по нажатию на иконку Chrome на панели задач рисует Windows, и расширение не может менять в нём порядок. Поэтому:

- **Список окон в расширении.** Окна с именами, числом вкладок и первой вкладкой. Имена хранятся в настройках по постоянному номеру окна (`docs/extension/specification.md`, раздел 3.1). Порядок меняется перетаскиванием, нажатие переносит в окно. Перетаскивание только меняет порядок в списке, сами окна не трогаются: можно переставить несколько окон, затем появляется панель с кнопками «Применить» — окна пересоздаются в новом порядке — и «Отменить» — список возвращается к порядку открытых окон.
- **Пересоздание окон в нужном порядке.** Расширение создаёт новые окна в порядке из своего списка и переносит в них вкладки. Windows сортирует окна Chrome на панели задач по времени создания: пересозданное окно оказывается последним в списке.
